Fixed the mobile stretched interface on portrait mode in BF1942  by modding the engine

Claude Code told me how it did it:

"1. Spotting the HUD: 3D world draws use a perspective projection, where far things look smaller. The HUD uses a flat one. I can tell them apart from the projection matrix the game sets before each draw.

2. Measuring each element: before drawing a HUD piece (the ticket count, the map, an ammo icon), I calculate on the CPU where its corners land on screen. That uses the same matrix math the graphics card would do.

3. Squeezing it back: I shrink its height by that 2.9× factor toward a fixed edge depending on where it sits. Things at the top move toward the top edge, things at the bottom toward the bottom edge, and things in the middle toward the center. Because everything in the same band moves together, the map and its icons stay lined up.

4. Leaving some things alone: big panels, like the scoreboard and loading photo, keep the old stretch so their layout isn't changed. On menu and loading screens, text shrinks around its own center so tap areas don't move."

中文：

通过修改引擎，修复了《战地1942》在手机竖屏模式下界面被拉伸的问题。

Claude Code 告诉我它是怎么做的：

“1. 识别 HUD：3D 世界的绘制使用透视投影，远处的物体看起来更小。HUD 使用平面投影。我可以根据游戏在每次绘制前设置的投影矩阵区分两者。

2. 测量每个元素：在绘制一块 HUD（兵力票数、地图或弹药图标）之前，我在 CPU 上计算它的各个角会落在屏幕的什么位置，使用与显卡相同的矩阵运算。

3. 压缩还原：根据元素所在位置，朝一个固定边缘把它的高度缩小至原来的 1/2.9。顶部元素朝上边缘移动，底部元素朝下边缘移动，中间元素朝中心移动。由于同一区带的所有元素一起移动，地图与图标仍能保持对齐。

4. 保留某些元素：计分板、加载图片这类大面板继续保持原来的拉伸，以免改变布局。在菜单和加载画面中，文字围绕自身中心缩小，因此点击区域不会移动。”
