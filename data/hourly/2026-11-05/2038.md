我通过魔改引擎，修好了 BF1942 竖屏模式下手机界面被拉伸的问题

Claude Code 告诉我它是怎么做的：

「1. 识别 HUD：3D 世界绘制用透视投影，远处的东西看起来更小。HUD 用的是平面投影。我可以从游戏每次绘制前设置的投影矩阵把它们区分开。

2. 测量每个元素：在绘制一块 HUD（剩余人数、小地图、弹药图标）之前，我在 CPU 上算出它的角点会落在屏幕哪里。用的是显卡会做的同一套矩阵运算。

3. 再压回去：按它所在位置，朝固定边缘把高度按 2.9× 那个系数压回去。顶部的往上边靠，底部的往下边靠，中间的往中心靠。同一条带里的东西一起动，所以小地图和它的图标还能对齐。

4. 有些东西不动：大面板，比如记分板和加载图，还保持原来的拉伸，免得布局乱掉。菜单和加载屏上的文字绕自己中心缩小，这样点击区域不会跑掉。」
